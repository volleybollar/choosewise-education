Evidence Toolkit · The S in WISE

What actually moves learning — and what just sounds like it does.

An independent, growing toolkit of teaching interventions ranked by the size of their effect on learning, cross-referenced to published meta-analyses. Built on Gareth Manning's open skill catalogue, with every effect size verified against independent research.

The Evidence Toolkit is the S — Select the right tool step of the WISE Framework. Once you've weighed the learning goal (W) and inspected what the subject calls for (I), this is where you select the teaching move with the strongest evidence base for your context. Then you evaluate the outcome (E) — and run the cycle again.

How this toolkit is organised

The toolkit is built domain by domain. Each domain has its own page with the full set of interventions, sortable by effect size, with a prompt builder for interrogating each claim in any AI chatbot.

1Pick a domain below — each covers one area of teaching practice.
2Browse interventions ranked by effect size, with sources cited.
3Interrogate any claim using the prompt builder in your preferred AI chatbot.
